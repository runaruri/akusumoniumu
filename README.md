# ACOUSMONIUM — 音と、空間と、物語。

アクースモニウムの鑑賞者・演奏者・企画者をつなぐ、日本語の12ページ構成の紹介サイトです。
HTML・CSS・JavaScriptで構成し、サイトを動かすためのパッケージインストールは不要です。

## まず開く

1. ZIPを展開します。
2. VS Codeの「ファイル → フォルダーを開く」で、展開した最新版のフォルダーを開きます。
3. `index.html` をブラウザーで開きます。サイト内リンク、検索、同梱朗読はローカルでも動作します。
4. 編集して保存した後、ブラウザーを再読み込みします。

このリポジトリを直接開く場合、公開ファイルは `dist/` 内にあります。配布ZIPでは `index.html` を開きやすいようにルートに配置しています。

共通ヘッダー・フッターは `templates/header.html` と `templates/footer.html` で管理します。変更後に `python tools/sync_layout.py` を実行すると全12ページへ同時に反映されます。各ページを単独で開ける静的HTMLの構成は維持しています。記事の見出しを変えた場合は、同じページの目次も更新してください。

本文を更新したら検索データを `python tools/update_search.py` で再生成できます（Python 3、追加ライブラリー不要）。

## 人物画像の差し替えと動き

- `assets/people/` に写真を置き、`image-settings.js` の `src`・`alt`・`credit` を変更します。トップ・人物一覧・個人ページへ一括反映されます。
- 写真枠は画面幅に追従し、スマートフォンでは人物紹介を1列にします。切り抜き位置も設定できます。
- 詳しい例は **docs/IMAGES.md**、控えめなアニメーションと停止方法は **docs/MOTION.md** を参照してください。
- 初期画像は音と空間の図版です。人物の顔写真や実際の公演写真ではありません。

## 音声について

短編『雨の向こうの駅』は本サイト用のAI生成作品で、合成音声を使用しています。紹介アーティストの作品・声・監修ではありません。
自分の朗読をその場で試すには、ラボの「自分の朗読音声を使う」からファイルを選びます（30MB・5分以内）。サーバーにアップロードしません。
同梱音声を恒久的に変更する場合は、2つの音声ファイルを用意し、`python tools/embed_audio.py chapter1.mp3 chapter2.mp3` を実行します。朗読テキストは `lab.js` と `story.html` も合わせて変更してください。
デモはHRTFによるヘッドホン向け仮想空間とエフェクトです。実会場の多スピーカーの音場を再現するものではありません。

## 追加したエフェクターとマイ設定

ラボの「声の質感を変える」で、4種類の効果をボタンから選びます。「加工なし」で解除します。効果の深さは原音との混合比です。残響・エコー・方向などは同時に調整できます。

- **ガビガビ**：振幅を段階化する量子化と飽和歪み。サンプルレートを下げる処理ではありません。
- **ラジオ**：1,700Hzを中心にしたバンドパスフィルター。
- **ロボット**：58Hzのリング変調。
- **トレモロ**：7Hzの音量変調。

「この聴こえ方を、残す」で名前を入力して保存。最大12件、呼び出し・上書き・削除に対応します。音量を含む各スライダー、選択効果と深さ、逆再生、ループ、原音比較を記録します。音声ファイル、章、再生位置は保存しません。保存を呼び出しても、停止中の音声を自動再生しません。
ブラウザーのlocalStorageを使用します。別の端末への移行やバックアップには「設定を書き出す」でJSONを保存し、「設定ファイルを読み込む」で追加します。読み込みは既存設定を消さず、同名には連番を付けます。
ファイルを直接開く場合のlocalStorage対応はブラウザーに依存します。保存できない旨が表示されたらJSONを書き出してください。安定した同一オリジンでの編集には、VS Codeの任意の静的プレビュー機能も使用できます。

## フォームと保存

- 企画メモは入力内容をTXTファイルに書き出します。送信機能ではありません。画面を離れる前に保存してください。
- 練習チェックは、そのブラウザーのlocalStorageに保存します。保存できない環境ではメッセージを表示します。
- サイト検索は同梱データを使います。外部検索サービスや解析タグは使用しません。

## 公開

配布ZIPのサイトファイルを静的ホスティングの公開フォルダーへ配置できます。README・docs・toolsは運用資料です。
現在のSitesは本人のみの閲覧権限を維持しています。公開範囲の変更は別途ホスティング側で行います。
ファイル名と相対パスを保つと、独自ドメインやサブフォルダーにも移しやすい構成です。
公開元の編集用ZIPへのリンクは、配布ZIP内のHTMLから除いています。ご自身の公開先で提供する場合はファイルを置いてリンクを追加してください。

## 検証と残る確認

- JavaScript構文、全ページの内部リンク・アンカー・資産参照、検索対象を機械検証。
- 音声エンジンの再生位置・一時停止・再開・速度変更・逆再生・ループ・効果切り替えの状態遷移を確認。
- トップ図版はHTML内のSVGです。画像の外部ホットリンクやフォントCDNへの依存はありません。
- この環境ではブラウザー操作による全ページの描画・実聴確認は実施できていません。公開前の確認手順は docs/RELEASE-CHECKLIST.md にまとめています。
