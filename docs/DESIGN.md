# デザインと編集の基準

2026年10月14日改訂。12ページすべてで、ヘッダー、本文の左端、目次の列、フッターの順序を統一。

- 共通コンテナーは最大1,160px。左右余白はPC 36px、スマートフォン20px。
- 記事は本文＋252pxの目次。1,000px以下では1列とし、本文前に折りたたみ目次を表示。
- 見出しは日本語明朝、本文は端末のゴシック体。本文はPC 16px、スマートフォン15px。補助文は原則12px以上。短い図版ラベル・欧文注記だけ小さくする。
- 紙色 #f7f5ef、墨色 #272a27、赤茶 #a34230。彩度の高い色は主な行動に限定。
- 写真風の架空会場は削除。トップには、スピーカーと聴き手の関係を伝える自作SVGを配置。実会場の測定図ではない。
- 記事タイトルの意味のない軌道装飾、毎ページ末尾の重複バナー、過剰な欧文の飾り見出しを整理。
- 人物紹介は名前と活動を中心にする。架空の肖像や推薦、受賞・助成採択の捏造はしない。
- ラボの音声機能・保存形式は継続。操作パネルの中だけ、機器としての濃色表示を使用。

## 編集する場所

- style.css：リセットと基本操作部品。
- pages.css：記事内の補助要素と音声プレイヤーの基本形。
- editorial.css：サイト共通グリッド、文字組、ホーム、記事、レスポンシブ。
- templates/：共通ヘッダー・フッター。tools/sync_layout.pyで全ページへ反映。

## 検証範囲

内部リンク・構文・DOM操作・音声エンジンの状態遷移を確認。実ブラウザーでの描画・実聴確認は、この作業環境では未実施。検証済みと扱わない。
