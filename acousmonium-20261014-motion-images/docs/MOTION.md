# 控えめな動き

ヘッダーのロゴは7秒周期で、各バーが順番に伸縮します。サイドバーの音の線は10秒周期です。文字・リンク・ヘッダー本体の位置は動かしません。音声とは連動しない装飾です。

ヘッダーの波形ボタンで停止・再開でき、設定はこのブラウザーに保存されます。OSの「視差効果を減らす／動きを減らす」が有効な場合は自動停止し、その設定を優先します。別のタブへ移ると停止します。

速度と振幅は editorial.css の `spatial-breathe` と `animation` を編集してください。動きと画像の反映処理は site-enhancements.js にまとめています。JavaScriptが使えない場合は静止した状態と標準の図版で表示します。

PC・タブレット・スマートフォンで共通のグリッドを使用します。650px以下では人物画像を1列にし、狭い画面ではヘッダーの余白と文字を縮小します。

この環境では実ブラウザーの目視検証は未実施です。横幅320px・390px・768px・1280pxの表示、縦長の写真への差し替え、動きの停止、OSの省モーション設定を公開環境で確認してください。
