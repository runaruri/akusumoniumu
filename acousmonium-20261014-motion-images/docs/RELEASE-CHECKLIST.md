# 公開前の確認

1. PCとスマートフォンのブラウザーで、トップ・記事・人物・ラボを表示し、横はみ出しや文字の重なりがないか確認する。
2. ナビゲーション、記事目次、サイト内検索、用語検索、練習チェック、企画メモのダウンロードを操作する。
3. ヘッドホンで朗読2章を再生し、4つのシーン、原音比較、一時停止、シーク、逆再生を確認する。自分の音声も1件試す。4種類のエフェクターを切り替え、深さ0と100%を比較する。マイ設定を保存し、画面再読み込み後に呼び出す。JSONの書き出し・読み込みを確認する。
4. 人物・公演・助成の出典と更新日を確認する。終了した公演を募集中として扱わない。実在の写真・作品を追加するときは掲載の条件を確認する。
5. 一般公開に切り替えた後、未ログインの端末で閲覧できるか確認する。現在の本人限定設定では広く共有できない。

機械チェック: `python tools/validate.py`
検証対象: ローカルリンク、見出しID、資産パス、検索項目。音の聞こえ方や実ブラウザーの描画はこのチェックでは評価しません。
